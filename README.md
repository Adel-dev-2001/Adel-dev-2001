## Selected projects

| Project | Purpose | Technologies |
| --- | --- | --- |
| [PromptVault](https://github.com/Adel-dev-2001/PromptVault) | A local, single-user library for AI-generated images and their prompts, with categories and favorites. Developed as a CS50x final project. | Python, Flask, SQLite, Jinja2 |
